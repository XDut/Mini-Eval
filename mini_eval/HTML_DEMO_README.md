# Mini-Eval — Deployed Browser Application

Launch the project from its Netlify page: [Mini-Eval on Netlify](https://YOUR-MINI-EVAL-SITE.netlify.app/).

Replace `YOUR-MINI-EVAL-SITE` with the real deployment hostname. Select a Qwen model on the page, click **Load Qwen in browser**, then **Run evaluation**. Initial public model downloads require internet access; inference uses Transformers.js and ONNX Runtime Web in the browser without a hosted inference API.

For evaluation methodology and limitations, see `mini_eval/README.md`.
